# Supervised Learning 📊

This folder contains implementations and experiments related to **Supervised Learning**.

Supervised learning focuses on training models using labeled data,
where each input has a corresponding target output.

---

## 📚 Topics Covered

### 🔹 Regression
- Linear Regression (from scratch)
- Multivariate Linear Regression
- Regularization (L1 / L2)
- Polynomial Regression

### 🔹 Classification
- Logistic Regression
- k-Nearest Neighbors (kNN)
- Support Vector Machines (SVM)
- Decision Trees
- Random Forests

---

## 📂 Structure

Each algorithm folder typically includes:

- Mathematical intuition behind the model
- Clean NumPy implementation (from scratch)
- Comparison with scikit-learn (when applicable)
- Visualization of results
- Notes on strengths and limitations
